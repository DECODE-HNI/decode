# 1.2.2 · Pollutant accounting

AssessmentApproach node: `APM_POLLUTANT`

| Field | Content |
|---|---|
| **Status in the model** | **computes** (v3.f; register demonstrator `ASSESS_POLLUTANT_ART_V_AL`) |
| **Uses (existing)** | Flow.casNumber, Flow.category, HAS_FLOW.amount, MODELED_BY datasets |
| **Schema Δ / done** | `HazardStatement` (12 GHS H statements) + `(:Flow)-[:HAS_HAZARD]->`; `Flow.hazardClass` (heavy-metal/CMR/acidifying-precursor/VOC, class screening) |
| **Base query** | `base_queries/pollutant_inventory.cypher` — now with `hazardClass` + `hCodes`, `$hazardOnly` |
| **Affected by** | Human-toxicity categories (populated for Variant A since 2026-08-29, see `ilcd_import/harmonize_noncas.cypher`); MFA (loss streams) |
| **Affects** | Digital product passport (SVHC/REACH/ESPR); LCA (toxicity interpretation) |
| **Open** | real hazard assignment per substance (CLP notation) instead of class screening; COD/BOD discharges stay unassessed (no EF3.1/ReCiPe category) |
